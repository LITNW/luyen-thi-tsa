# LIT brand assets

All assets in this folder are vector SVG files. They are Canva-independent and can be opened in any modern browser, imported into Figma/Canva Free, or used by the application after a separately reviewed integration change.

| File | Use |
|---|---|
| `lit-symbol.svg` | Primary geometric symbol on light backgrounds |
| `lit-horizontal.svg` | Primary horizontal lockup on light backgrounds |
| `lit-symbol-mono.svg` | Single-color symbol; inherits `currentColor` |
| `lit-horizontal-mono.svg` | Single-color horizontal lockup; inherits `currentColor` |

The mark is a working concept, not a trademark clearance or final legal approval. Do not stretch, rotate, redraw or add effects. Use the horizontal lockup when the available width permits; use the symbol alone for compact spaces and favicon contexts.

The wordmark uses Inter with Arial fallback. For the single-color variants, set the SVG's `color` / CSS `color` to the intended foreground and ensure sufficient contrast with the background.

Source-of-truth colors and spacing: `docs/brand/lit-design-tokens.css`. Full guidance: `docs/brand/LIT-BRAND-SYSTEM.md`.
